# IBM HR Employee Attrition & Performance Dashboard

## 📊 Project Overview

This project uses Microsoft Power BI to analyze employee attrition and workforce patterns. The dashboard explores employee data across multiple dimensions to understand attrition trends and workforce characteristics through interactive visualizations and key performance indicators (KPIs).

## 🎯 Project Objectives

- Analyze employee attrition and workforce patterns.
- Calculate key HR metrics, including attrition rate and average years of service.
- Compare employee attrition across departments, job roles, and other employee attributes.
- Explore overtime patterns and their relationship with employee attrition.
- Present findings through an interactive Power BI dashboard.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** — Dashboard development and visualization
- **Power Query** — Data cleaning and transformation
- **DAX (Data Analysis Expressions)** — KPI calculations and measures
- **CSV** — Source dataset

## 📁 Dataset

The dataset contains information about **1,470 employees** and includes employee-related attributes used to analyze attrition and workforce characteristics.

The analysis covers dimensions such as:
- Department
- Job Role
- Age
- Gender
- Education
- Overtime
- Other employee attributes available in the dataset

## 📈 Key Performance Indicators

The dashboard highlights the following metrics:

- **Employee Count:** 1,470
- **Attrition Rate:** 16.12%
- **Average Years:** 7.01
- **Overtime Rate:** 28.30%

These KPIs provide a high-level overview of employee attrition and workforce patterns.

## 📊 Dashboard Features

- KPI cards for key HR metrics
- Attrition analysis across employee dimensions
- Department and job role comparisons
- Analysis of employee attributes such as age, gender, education, and overtime
- Interactive slicers for exploring different employee groups
- Visual summaries to support HR data analysis

## ⚙️ Project Workflow

1. Imported the employee dataset into Power BI.
2. Cleaned and transformed the data using Power Query.
3. Created DAX measures for key HR metrics.
4. Developed visuals to compare attrition across employee dimensions.
5. Added slicers and interactive features.
6. Built a dashboard to summarize key workforce patterns.
